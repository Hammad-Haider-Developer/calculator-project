# calculator-project

This is a simple and responsive Calculator Web Application built using HTML, CSS, and JavaScript.<br>
The calculator performs basic arithmetic operations such as addition, subtraction, multiplication, and division, along with a clear screen button to reset the input.<br>

The main purpose of this project is to strengthen core JavaScript concepts, DOM manipulation, and user interface design for front-end development practice.<br>

✨ Features:<br>
Addition, Subtraction, Multiplication, Division<br>
Clear Screen Button<br>
Responsive and Clean UI<br>
User-friendly Interface<br>
Real-time input display<br>
Lightweight and fast performance<br>

🛠️ Technologies Used:<br>
HTML5<br>
CSS3<br>
JavaScript (Vanilla JS)<br>

🚀 How to Run the Project:<br>
Download or clone the repository<br>
Open the project folder<br>
Open index.html in your browser<br>
Start using the calculator<br>
🎯 Purpose of Project:<br>
This project is created for front-end development practice and to demonstrate basic JavaScript functionality in a real-world mini application.
